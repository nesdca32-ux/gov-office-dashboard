# แดชบอร์ดหน่วยงานราชการในพื้นที่

Interactive dashboard แสดงผลวิเคราะห์เบื้องต้นของสำนักงาน/หน่วยงานภาครัฐในพื้นที่ **19,334 แห่ง** ครบทั้ง 22 กระทรวง/กลุ่ม แยกตามกระทรวง ระดับพื้นที่ ประเภทการบริหาร และ 23 กลุ่มภารกิจ พร้อม Matrix ความซ้ำซ้อน กรณีศึกษากระทรวงเกษตรและสหกรณ์ และข้อเสนอการจัดโครงสร้างแบบ Agenda-based

## เปิดใช้งาน
- เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร (ใช้งานออฟไลน์ได้)
- หรือเปิดผ่าน GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`

## เนื้อหา
- **ภาพรวม:** KPI, กราฟ Pareto รายกระทรวง, สัดส่วนตามระดับพื้นที่
- **รายกระทรวง:** กราฟแท่งซ้อน และ Heatmap ที่เจาะลึกรายกรมได้
- **กลุ่มภารกิจ & Matrix ความซ้ำซ้อน:** ปรับเกณฑ์ระดับความซ้ำซ้อนได้
- **กรณีศึกษา กษ.:** รอยเท้าในพื้นที่ 3,731 แห่ง, โครงสร้าง 3 ชั้น, 7 กลุ่มงาน, ศูนย์วิจัย
- **ข้อสังเกต & ข้อเสนอ:** ข้อสรุป, กรณีทางหลวง 2 กรม (215 สำนักงาน), ปศุสัตว์ Silo → 3 Agenda, เทียบญี่ปุ่น/เกาหลีใต้, การจัดตามวาระ, ข้อเสนอ 4 ระยะ และขั้นตอนต่อไป
- **ข้อมูล & ข้อจำกัด:** คุณภาพข้อมูล, บันทึกการทวนสอบ, ตารางข้อมูลที่ค้นหาและดาวน์โหลด CSV ได้

## ที่มาและข้อจำกัด
ที่มา: `matrix + Dashboard.xlsx` และสไลด์ “หน่วยงานราชการในพื้นที่” (ตุลาคม 2569)

⚠ ข้อมูลเบื้องต้น: 90.5% ของแถวข้อมูลยังไม่ทวนสอบ (24.1% ของจำนวนสำนักงาน) และอีก 53.2% เป็นค่าประมาณ/รอตรวจสอบ ใช้จัดลำดับประเด็นที่ควรศึกษาต่อเท่านั้น ยังไม่ควรใช้สรุปว่าหน่วยงานใดซ้ำซ้อนหรือควรยุบรวม ข้อเสนอในแดชบอร์ดเป็นข้อเสนอเชิงทิศทาง ต้องยืนยันภารกิจตามกฎหมายก่อนตัดสินใจ
